# Union ERP - Training Portal 2024

Welcome to the **Union ERP Training Portal 2024** repository.

## Overview
This repository contains the web application front-end for the Union ERP Training Portal (2024 edition).

## Features
- **Training Modules Overview**: Information on key Union ERP modules (Financials, HR, Supply Chain).
- **Lightweight Front-End**: Built with standard HTML5, CSS3, and JavaScript.

## How to Run Locally
You can serve the static files using Python's built-in HTTP server or any standard web server.

```bash
# Start local server
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000` in your web browser.
